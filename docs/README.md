# Documentação do MeuGasto

Esta pasta reúne a documentação versionada do projeto. Documentos duráveis devem ser mantidos aqui e atualizados no mesmo PR da mudança de código correspondente.

## Organização

- [Arquitetura](architecture/): decisões e desenho técnico em vigor.
- [ADRs](adr/): decisões arquiteturais registradas e seus contextos.
- [Produto](product/): roadmap e backlogs de produto.
- [Segurança](security/): planos e documentação de privacidade e segurança.

## Fontes de verdade

- `AGENTS.md`: regras do projeto, invariantes de release e cobertura oficial de NFC-e por UF.
- `CHANGELOG.md` e GitHub Releases: versões publicadas.
- GitHub Issues/Projects: unidades de trabalho priorizadas e acompanháveis.

Não adicione logs, transcrições de agentes ou estado local de ferramentas a esta pasta. Esses artefatos devem permanecer ignorados pelo Git.
